# Автоходы

1. Перезагрузить расширение после обновления: в manifest добавлено разрешение `scripting`.
2. Обновить страницу тестовой партии, чтобы загрузился новый content script.
3. Включить анализ и **Auto move**. Цвет игрока определяется автоматически.

Оператор выбирает тестовую партию. Автоходы не проверяют метки `ai`, `human` или `unknown`. Цвет читается из `game.getPlayingAs()` на Chess.com и `round.data.player.color` на игровом экране Lichess. Поворот доски и текущая очередь хода не используются для определения игрока. Если сторона не определена, автоход не выполняется. Доска анализа Lichess не имеет назначенной стороны игрока. Auto move по умолчанию выключен; настройка сохраняется.

Исполнитель работает только с активной сессией и легальным результатом для её текущего FEN и ревизии. Подтверждает выполненный ход по новой позиции либо префиксу истории, если противник уже ответил. Повторные результаты не отправляют тот же ход снова. Выключение, потеря связи и закрытие страницы отменяют ожидающее выполнение.

Chess.com: используется API доски `game.move` с `userGenerated: true`, при отсутствии API — события указателя. Lichess: игровой контроллер захватывается при его штатной инициализации через `site.asset.loadEsmPage` на `document_start`; цвет берётся из `data.player.color`, ход выполняется через `pluginMove`. Обёртка использует `loadEsm` и не пытается менять неизменяемые экспорты модуля asset. Публичный Chessground API остаётся резервным вариантом, если он доступен. Вызов выполняется через `scripting.executeScript` в контексте страницы; произвольный код от страницы не принимается.

В игровом контроллере Lichess поле `step.fen` может содержать только расстановку фигур. Исполнитель сравнивает её отдельно, проверяя очередь хода и номер полухода по контроллеру. Если дополнительные поля FEN присутствуют, очередь и права рокировки также сверяются. Устаревший запрос (`POSITION_CHANGED`) отбрасывается с повторным чтением доски; новый результат может выполнить ход без переключения Auto move. Тот же устаревший запрос повторно не отправляется.

Если доска не приняла ход или не подтвердила новую позицию, показывается `AUTO_MOVE_FAILED`; автоматического повтора для этой позиции нет. После проверки состояния можно выключить и снова включить Auto move.

## Проверено

- 29 тестов: конфигурация, автоматическое определение стороны, легальность, активная вкладка, устаревшие результаты, отсутствие повторов, подтверждение и отмена, сериализация функции выполнения. Регрессии проверяют сокращённый FEN, включая `1. e4 e5 2. f4` со скриншота, обе стороны и смену позиции во время отправки хода с последующим выполнением актуального результата.
- Chrome, Chess.com: ход в партии с компьютерным ботом и ответ бота (`e4 c5`); превращение в коня на доске анализа.
- Chrome, Lichess: изменение FEN после `analysis.playUci` и после выбора клеток через Chessground API.
- Popup: ручной выбор стороны удалён, управление проверено на тестовом состоянии.

Исправление игрового экрана дополнительно проверено тестами раннего запуска с неизменяемым пространством имён модуля, отсутствующим глобальным Chessground, цветом игрока, отличным от ориентации, вызовом `pluginMove`, превращением и отказом при просмотре старой позиции. На открытой странице Lichess проверена совместимость обёртки с настоящим загрузчиком `site.asset`. Полная партия Lichess и загрузка обновлённого расширения в Firefox требуют операторского прогона. Браузерные проверки выше вызывали функцию выполнения на страницах напрямую, без установленного пакета расширения.
